# 🖥️ Exemplo Prático de JRadioButton em Java Swing

Aplicação desenvolvida em **Java** utilizando a biblioteca gráfica **Java Swing** para demonstrar o uso de botões de rádio (`JRadioButton`), agrupamento de opções (`ButtonGroup`) e manipulação de eventos de clique.

## 🚀 Funcionalidades do Projeto
O projeto está estruturado em múltiplos painéis (`JPanel`) com bordas customizadas (`TitledBorder`), contendo diferentes cenários de escolha única:
1. **Seleção de Opções Simples:** Alternativa entre opções genéricas com feedback em caixa de diálogo (`JOptionPane`).
2. **Seleção de Sexo:** Demonstração de escolha exclusiva para formulários cadastrais.
3. **Formas de Pagamento:** Simulação de escolha de método de pagamento (Cartão, Boleto, Pix).

## 🛠️ Tecnologias Utilizadas
* **Java 21**
* **Java Swing** (AWT / Layout Managers: `GridLayout`, `FlowLayout`)
* **IntelliJ IDEA**

## 💡 Conceitos Aplicados
* Organização de componentes visuais com `JFrame` e `JPanel`.
* Uso de `ButtonGroup` para garantir a exclusividade na seleção de `JRadioButton`.
* Tratamento de eventos de ação (`ActionListener`) com expressões *Lambda*.
* Exibição de alertas dinâmicos utilizando `JOptionPane`.
